One-Pass Streaming OpInf

The one-pass workflow reads every full-order snapshot exactly once. Each snapshot updates a low-rank SVD of the snapshot matrix,

\[\mathbf{X} = [\mathbf{x}_1, \ldots, \mathbf{x}_K] \approx \mathbf{V}\boldsymbol{\Sigma}\mathbf{W}^\top,\]

and is then discarded. The left singular vectors $\mathbf{V}$ are the POD basis, and the reduced snapshots come for free from the right factor,

\[\hat{\mathbf{X}}^\top = \mathbf{X}^\top\mathbf{V} \approx \mathbf{W}\boldsymbol{\Sigma},\]

so the OpInf data matrix $\mathbf{D}$ can be formed without revisiting the full-order data. Reduced time derivatives are obtained either

  • by applying a finite-difference matrix $\mathbf{E}$ (see finite_diff_matrix) to the reduced snapshots, $\dot{\hat{\mathbf{X}}}^\top \approx \mathbf{E}^\top\mathbf{W}\boldsymbol{\Sigma}$ (finite_diff=true, the default), or
  • by streaming the derivative snapshots as well and compressing them with a second iSVD $\dot{\mathbf{X}} \approx \mathbf{P}\mathbf{S}\mathbf{Q}^\top$ (finite_diff=false).

The final least-squares (optionally Tikhonov-regularized) problem is only of size $K \times d$ and is solved by compute_stream_operators.

SVD methods

isvd_methodMethodNotes
:bakerdeterministic incremental SVD (Baker, Gallivan & Van Dooren)rank grows up to rank and is truncated thereafter; requires the first snapshot x_init
:sketchyrandomized streaming sketch (Tropp et al.)requires the total number of snapshots n_snapshots; the SVD is recovered at the end with compute_svd_sketchy!

Typical usage

using LiftAndLearn
const LnL = LiftAndLearn

options = LSOpInfOption(
    system=SystemStructure(state=[1, 2], control=1),
    data=DataStructure(Δt=Δt, deriv_type="SI"),
    with_reg=true, λ=TikhonovParameter(A=1e-9, A2=1e-9, B=1e-9),
)

# Initialize with the first snapshot, then stream the rest
stream = OnePassStreamingOpInf(X[:, 1]; options=options, n_state=n, n_input=1, rank=rmax)
for k in 2:K
    LnL.stream!(stream, X[:, k])        # e.g., read from disk or a running solver
end

# Reduced operators of any dimension r ≤ rmax
E, idx = LnL.finite_diff_matrix(options.data.deriv_type, K, Δt)
op = LnL.compute_stream_operators(stream, E, idx; U=U, rank=r)
Vr = stream.V[:, 1:r]                   # matching POD basis
Several trajectories

When the snapshots come from several trajectories streamed back to back, build one finite-difference matrix per trajectory and pass their block-diagonal concatenation (e.g., BlockDiagonal(Es) from BlockDiagonals.jl) together with the concatenated, shifted index vectors.

Truncation

The Baker iSVD with rank < n is a single-pass approximation: once the rank cap is reached, discarded directions cannot be recovered later. Choose rank somewhat larger than the reduced dimension $r$ you intend to use.

API

LiftAndLearn.OnePassStreamingOpInf — Function
OnePassStreamingOpInf(; ...)
OnePassStreamingOpInf(
    x_init;
    xdot_init,
    options,
    n_state,
    n_input,
    n_snapshots,
    rank,
    finite_diff,
    isvd_method,
    sketch_size
)

Create a one-pass Streaming OpInf object that compresses snapshot data on the fly.

In one-pass Streaming OpInf every full-order snapshot is seen exactly once: it updates a low-rank (incremental or sketched) SVD of the snapshot matrix and is then discarded. After all data has been streamed, the POD basis and the reduced data needed by OpInf are read off the compressed factors and the reduced operators are computed with compute_stream_operators.

Arguments

  • x_init::AbstractVector{T}=Float64[]: the first snapshot (required, nonzero, length n_state for isvd_method=:baker; ignored for :sketchy).

Keyword Arguments

  • xdot_init::AbstractVector{T}=T[1]: the first time-derivative snapshot (only used when finite_diff=false).
  • options::LSOpInfOption: standard OpInf options defining the model structure.
  • n_state::Int: full state dimension $n$.
  • n_input::Int=0: input dimension $m$.
  • n_snapshots::Int=1: total number of snapshots $K$ (required for :sketchy).
  • rank::Int=1: maximum (truncation) rank of the SVD.
  • finite_diff::Bool=true: if true, only snapshots are streamed and time derivatives are later approximated by a finite-difference matrix; if false, derivative snapshots are streamed too (:baker only).
  • isvd_method::Symbol=:baker: :baker (deterministic incremental SVD of Baker et al.) or :sketchy (randomized streaming sketch of Tropp et al.).
  • sketch_size::Tuple{Int,Int,Int}=(0,0,0): (k, s, ζ) for :sketchy (range sketch size, core sketch size, nonzeros per column of the sparse test matrices). Zeros select the defaults k = 4rank + 1, s = 2k + 1, ζ = min(k, 8).

Returns

  • obj: an OnePassStreamingOpInf1 (:baker, finite_diff=true), OnePassStreamingOpInf2 (:baker, finite_diff=false), or OnePassStreamingOpInfSketchy (:sketchy).

Examples

stream = OnePassStreamingOpInf(X[:, 1]; options=options, n_state=n, n_input=1, rank=10)
for k in 2:size(X, 2)
    LiftAndLearn.stream!(stream, X[:, k])
end
E, idx = LiftAndLearn.finite_diff_matrix(options.data.deriv_type, size(X, 2), Δt)
op = LiftAndLearn.compute_stream_operators(stream, E, idx; U=U)
Vr = stream.V   # POD basis

  • Tropp, J. A., Yurtsever, A., Udell, M., and Cevher, V. Streaming low-rank matrix approximation with an application to scientific simulation. SIAM Journal on Scientific Computing, 41(4), 2019.

LiftAndLearn.OnePassStreamingOpInf1 — Type
mutable struct OnePassStreamingOpInf1{T<:Number}

One-pass Streaming OpInf state when the time derivative is approximated by finite differences (finite_diff=true, Baker iSVD).

Only the snapshot matrix is compressed on the fly with an incremental SVD $\mathbf{X} \approx \mathbf{V}\boldsymbol{\Sigma}\mathbf{W}^\top$. Because the reduced snapshots are $\hat{\mathbf{X}}^\top = \mathbf{W}\boldsymbol{\Sigma}$, the reduced time-derivative data can be formed afterwards by applying a finite-difference matrix to $\mathbf{W}\boldsymbol{\Sigma}$ without revisiting the full-order data. Created by OnePassStreamingOpInf.

Fields

  • V::AbstractArray{T}: left singular vectors (POD basis), $n \times r_s$.
  • Σ::AbstractVector{T}: singular values, length $r_s$.
  • W::AbstractArray{T}: right singular vectors, $K \times r_s$ (one row per snapshot).
  • state_dim::Int: full state dimension $n$.
  • input_dim::Int: input dimension $m$.
  • num_of_snapshots::Int: number of snapshots streamed so far $K$.
  • r_s::Int: current rank of the iSVD.
  • rmax::Int: maximum rank kept by the iSVD (truncation rank).
  • Cs, q1cache, q2cache, xperp_cache: preallocated work arrays.
  • options::LSOpInfOption: standard OpInf options defining the model structure.

LiftAndLearn.OnePassStreamingOpInf2 — Type
mutable struct OnePassStreamingOpInf2{T<:Number}

One-pass Streaming OpInf state when time-derivative data are streamed alongside the snapshots (finite_diff=false, Baker iSVD).

Both the snapshot matrix $\mathbf{X} \approx \mathbf{V}\boldsymbol{\Sigma}\mathbf{W}^\top$ and the derivative matrix $\dot{\mathbf{X}} \approx \mathbf{P}\mathbf{S}\mathbf{Q}^\top$ are compressed with incremental SVDs. Created by OnePassStreamingOpInf.

Fields

  • V::AbstractArray{T}, Σ::AbstractVector{T}, W::AbstractArray{T}: iSVD of the snapshots.
  • P::AbstractArray{T}, S::AbstractVector{T}, Q::AbstractArray{T}: iSVD of the derivatives.
  • state_dim::Int: full state dimension $n$.
  • input_dim::Int: input dimension $m$.
  • r_s::Int: current rank of the snapshot iSVD.
  • r_d::Int: current rank of the derivative iSVD.
  • rmax::Int: maximum rank kept by both iSVDs.
  • Cs, Cd, q1cache, q2cache, xperp_cache: preallocated work arrays.
  • options::LSOpInfOption: standard OpInf options defining the model structure.

LiftAndLearn.OnePassStreamingOpInfSketchy — Type
mutable struct OnePassStreamingOpInfSketchy{T<:Number}

One-pass Streaming OpInf state based on a randomized sketch of the snapshot matrix (isvd_method=:sketchy).

Each streamed snapshot updates three linear sketches (range, co-range, and core) with sparse random sign test matrices; the truncated SVD of the snapshot matrix is recovered at the end with compute_svd_sketchy!. The total number of snapshots must be known in advance. Created by OnePassStreamingOpInf.

Fields

  • V::AbstractArray{T}, Σ::AbstractVector{T}, W::AbstractArray{T}: truncated SVD of the snapshot matrix (populated by compute_svd_sketchy!).
  • Ξ::AbstractArray{T}: range test matrix, $k \times n$.
  • Ω::AbstractArray{T}: co-range test matrix, $k \times K$.
  • Φ::AbstractArray{T}: core test matrix, $s \times n$.
  • Ψ::AbstractArray{T}: core test matrix, $s \times K$.
  • Xcorange::AbstractArray{T}: co-range sketch, $k \times K$.
  • Xrange::AbstractArray{T}: range sketch, $n \times k$.
  • Xcore::AbstractArray{T}: core sketch, $s \times s$.
  • H::AbstractArray{T}: sparse innovation buffer, $n \times K$.
  • k::Int: range sketch size.
  • s::Int: core sketch size.
  • input_dim::Int: input dimension $m$.
  • rmax::Int: target rank.
  • num_of_snapshots::Int: number of snapshots streamed so far.
  • options::LSOpInfOption: standard OpInf options defining the model structure.

References

  • Tropp, J. A., Yurtsever, A., Udell, M., and Cevher, V. Streaming low-rank matrix approximation with an application to scientific simulation. SIAM Journal on Scientific Computing, 41(4):A2430–A2463, 2019.

LiftAndLearn.stream! — Method
stream!(obj, x; tol)

Stream one full-order snapshot x into a one-pass object (finite-difference variant), updating its incremental SVD.

The new snapshot is orthogonalized twice against the current basis, the small arrowhead matrix is diagonalized, the factors $\mathbf{V}, \boldsymbol{\Sigma}, \mathbf{W}$ are updated and truncated to obj.rmax, and the basis is re-orthogonalized if needed.

Arguments

  • obj::OnePassStreamingOpInf1: the one-pass object (mutated).
  • x::AbstractVector{T}: the next snapshot (length $n$).

Keyword Arguments

  • tol::T=1e-12: orthogonality tolerance that triggers re-orthogonalization of $\mathbf{V}$.

Returns

  • nothing; mutates obj.

LiftAndLearn.compute_stream_operators — Function
compute_stream_operators(obj, E, indices; U, rank)

Compute the reduced operators from a finite-difference one-pass object using the contiguous snapshot range indices[1]:indices[2].

Same as the indices::AbstractVector method but takes the range as a tuple.

Arguments

  • obj: the one-pass object after all snapshots have been streamed.
  • E::AbstractArray{T}: finite-difference matrix of size $K \times K'$ such that $\mathbf{X}\mathbf{E}$ approximates the time derivatives (see finite_diff_matrix). For several trajectories use a block-diagonal matrix.
  • indices::Tuple{<:Int,<:Int}: first and last snapshot index paired with the columns of E.

Keyword Arguments

  • U::AbstractArray{T}=[0.0]: input data with one row per snapshot ($K \times m$; an $m \times K$ matrix is transposed automatically). Only linear inputs (B) are supported.
  • rank::Int=obj.rmax: reduced dimension $r \le$ obj.rmax used to build the model.

Returns

  • operators::Operators: the learned reduced operators (A, B, A2u, K, ...) with the full operator matrix in operators.O.

compute_stream_operators(obj, E, indices; U, rank)

Compute the reduced operators from a finite-difference one-pass object using the snapshots at the positions indices.

The reduced snapshots are $\hat{\mathbf{X}}^\top = \mathbf{W}\boldsymbol{\Sigma}$ and the reduced time derivatives are $\mathbf{E}^\top\mathbf{W}\boldsymbol{\Sigma}$; the least-squares (optionally Tikhonov-regularized, per obj.options) OpInf problem is then solved.

Arguments

  • obj: the one-pass object after all snapshots have been streamed.
  • E::AbstractArray{T}: finite-difference matrix of size $K \times K'$ such that $\mathbf{X}\mathbf{E}$ approximates the time derivatives (see finite_diff_matrix). For several trajectories use a block-diagonal matrix.
  • indices::Union{Array{<:Int},UnitRange}: snapshot indices (rows of $\mathbf{W}$) paired with the columns of E, e.g. the index range returned by finite_diff_matrix.

Keyword Arguments

  • U::AbstractArray{T}=[0.0]: input data with one row per snapshot ($K \times m$; an $m \times K$ matrix is transposed automatically). Only linear inputs (B) are supported.
  • rank::Int=obj.rmax: reduced dimension $r \le$ obj.rmax used to build the model.

Returns

  • operators::Operators: the learned reduced operators (A, B, A2u, K, ...) with the full operator matrix in operators.O.
