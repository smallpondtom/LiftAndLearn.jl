Lifting

This page gives an explanation for the mathematical concept of lifting and provides example code for its implementation.

Lift Map Structure

LiftAndLearn.lifting — Type
struct lifting

Lifting map for Lift & Learn (LnL).

Constructed as lifting(N, Nl, lift_funcs), where lift_funcs contains the Nl - N functions that compute the additional lifted variables. Each lifting function receives the original variables as a vector x of length N (one entry per variable, each a vector or matrix of grid values) and returns the new lifted variable, e.g. x -> x[1] .^ 2.

Fields

  • N::Int64: number of variables of the original nonlinear dynamics.
  • Nl::Int64: number of variables of the lifted system.
  • lift_funcs::AbstractArray{Function}: the Nl - N lifting functions.
  • map::Function: map the data to all lifted variables (original variables followed by the additional lifted ones). Accepts a vector of per-variable arrays, or a stacked array map(x, gp) whose rows are split into N blocks of gp grid points.
  • mapNL::Function: map the data to only the additional lifted variables; same call signatures as map.

Notes

  • Throws an error if Nl - N != length(lift_funcs).

Examples

lifter = lifting(2, 3, [x -> x[1] .^ 2])
W = lifter.map(X, gp)   # X has 2*gp rows, W has 3*gp rows
source
Tip

For a simple pendulum we have

\[\begin{bmatrix} \dot{x}_1 \\ \dot{x}_2 \end{bmatrix} = \begin{bmatrix} x_2 \\ -\frac{g}{l} \sin(x_1) \end{bmatrix}\]

The lifted system becomes

\[\begin{bmatrix} \dot{x}_1 \\ \dot{x}_2 \\ \dot{x}_3 \\ \dot{x}_4 \end{bmatrix} = \begin{bmatrix} x_2 \\ -\frac{g}{l} x_3 \\ x_2 x_4 \\ -x_2 x_3 \end{bmatrix}\]

when $x_3 = \sin(x_1)$ and $x_4 = \cos(x_1)$. Which if coded, would look like this:

lifter = LnL.lifting(2, 4, [x -> sin.(x[1]), x -> cos.(x[1])])

Construct Lifted POD Basis from Data

LiftAndLearn.lifted_basis — Function
lifted_basis(W, Nl, gp, ro)

Create the block-diagonal Proper Orthogonal Decomposition (POD) basis of the lifted snapshot data, with one POD basis per lifted variable.

The rows of W are split into Nl blocks of gp rows; the leading ro[i] left singular vectors of block i form the i-th diagonal block of the basis.

Arguments

  • W::Matrix: lifted snapshot matrix of size $(N_l \cdot gp) \times K$ (columns = snapshots).
  • Nl::Real: number of lifted variables.
  • gp::Integer: number of grid points of each variable.
  • ro::Vector: reduced dimension of each variable's basis (each ro[i] <= gp).

Returns

  • Vr::BlockDiagonal: block-diagonal basis of size $(N_l \cdot gp) \times \sum_i ro_i$.
source

LnL = LiftAndLearn
