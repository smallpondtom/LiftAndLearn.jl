LiftAndLearn.LiftAndLearn — Module
LiftAndLearn

Julia package for nonintrusive model reduction of polynomial (and lifted nonlinear) dynamical systems.

Main features:

  • intrusive model reduction by Proper Orthogonal Decomposition (POD) projection (pod),
  • standard and Tikhonov-regularized Operator Inference (OpInf) (opinf),
  • Lift & Learn (LnL) with user-defined lifting maps (lifting, lifted_basis),
  • Energy-Preserving OpInf (EP-OpInf) via constrained optimization (epopinf),
  • Streaming OpInf (one-pass and two-pass variants) for large or streaming data sets.

Data-layout convention: state snapshot matrices have rows = state dimension and columns = time (each column is a snapshot).

LiftAndLearn._default_nonlinear_function — Method
_default_nonlinear_function(ops)

Build the default nonlinear right-hand side $\mathbf{f}(\mathbf{x}, \mathbf{u})$ of ops from its non-redundant polynomial operators and its bilinear operator. Internal helper.

The returned closure evaluates $\mathbf{A}_{2u}(\mathbf{x}\oslash\mathbf{x}) + \mathbf{A}_{3u}(\mathbf{x}\oslash\mathbf{x}\oslash\mathbf{x}) + \mathbf{A}_{4u}(\cdots) + \sum_i (\mathbf{N}_i\mathbf{x})u_i$, where absent (zero) operators contribute zero.

Arguments

  • ops::Operators: operators of the system.

Returns

  • f::Function: closure (x, u) -> ... (it reads the fields of ops at call time).

Notes

  • For more than one input (size(ops.B, 2) > 1) the bilinear term uses ops.N[i], i.e. N must then be a vector of $n \times n$ matrices.

LiftAndLearn.compute_regularization_matrix — Method
compute_regularization_matrix(Γ)
compute_regularization_matrix(Γ, method)

Compute a square-root factor $\boldsymbol{\Gamma}^{1/2}$ of the Tikhonov matrix, used as the lower block of the augmented system in solve_augmented_system. Internal helper.

Arguments

  • Γ::AbstractMatrix{T}: Tikhonov matrix of size $n \times n$.
  • method::Symbol=:cholesky: :cholesky (upper Cholesky factor $\mathbf{U}$ with $\mathbf{U}^\top\mathbf{U} = \boldsymbol{\Gamma}$, used if Γ is positive definite), :eigen ($\mathbf{V}\boldsymbol{\Lambda}^{1/2}$ from a symmetric eigendecomposition, which satisfies $\mathbf{S}\mathbf{S}^\top = \boldsymbol{\Gamma}$) or anything else for the element-wise square root.

Returns

  • Γsq::AbstractMatrix: the square-root factor.

Notes

  • A diagonal Γ (the default built by tikhonov_matrix!) is factored exactly by the element-wise square root, which preserves sparsity.
  • If Γ is not positive definite (e.g. it has zero diagonal entries) or the Cholesky factorization fails, the element-wise square root sqrt.(Γ) is returned, which is exact only for diagonal Γ.

LiftAndLearn.ephec_opinf — Method
ephec_opinf(D, Rt, dims, operators_symbols, options, IG)

Solve the Energy-Preserving OpInf (EP-OpInf) problem with hard equality constraints (EPHEC) using JuMP and Ipopt.

Minimizes $\|\mathbf{D}\mathbf{O}^\top - \mathbf{R}^\top\|_F^2 + \lambda_{\text{lin}}\|\hat{\mathbf{A}}\|_F^2 + \lambda_{\text{quad}}\|\hat{\mathbf{F}}\|_F^2$ subject to the energy-preserving constraints $h_{ijk} + h_{jik} + h_{kji} = 0$ on the quadratic operator for all $1 \leq k \leq j \leq i \leq n$.

Arguments

  • D::Matrix: data matrix of size $K \times d$.
  • Rt::Union{Matrix,Transpose}: transposed derivative data $\mathbf{R}^\top$ of size $K \times r$.
  • dims::AbstractArray: number of columns of D belonging to each operator.
  • operators_symbols::AbstractArray: operator symbols in the same order as dims.
  • options::AbstractOption: an EPHECOpInfOption.
  • IG::Operators: initial guess of the operators (used if options.optim.initial_guess=true).

Returns

  • op::Operators: the inferred operators.

Notes

  • Implemented for linear + quadratic state operators (plus optional linear input and constant terms) only.
  • In the redundant form (options.optim.nonredundant_operators=false) the second term of the constraint is coded as Hhat[k, n*(k-1)+i], whereas epsic_opinf uses Hhat[j, n*(k-1)+i].
source

LiftAndLearn.rls_cpu! — Method
rls_cpu!(obj, D, R, Q)

CPU implementation of one RLS update (rank-1 or block). Internal helper.

With $\mathbf{G} = \mathbf{P}\mathbf{D}^\top/\lambda$ and $\mathbf{C} = \mathbf{D}\mathbf{P}\mathbf{D}^\top/\lambda + \mathbf{Q}$, the update is $\mathbf{K} = \mathbf{G}\mathbf{C}^{-1}$, $\mathbf{O} \leftarrow \mathbf{O} + \mathbf{K}(\mathbf{R} - \mathbf{D}\mathbf{O})$, and $\mathbf{P} \leftarrow (\mathbf{P} - \lambda\mathbf{K}\mathbf{G}^\top)/\lambda$.

Arguments

  • obj::RLSCache{T}: the RLS state (mutated).
  • D::AbstractArray{T}: data block, $M \times N$.
  • R::AbstractArray{T}: right-hand side block, $M \times n$.
  • Q::Union{T,AbstractMatrix{T}}: noise covariance of the block.

Returns

  • nothing; mutates obj.

LiftAndLearn.select_optimal_method — Method
select_optimal_method(A, b, Γ, solver)

Select the Tikhonov solution method from the solver flags and the problem size. Internal helper.

The first matching rule is used:

  1. SVDTruncation() if solver.use_svd_truncation and the condition estimate exceeds 1e12;
  2. NormalForm() if solver.use_normal_form, $m > 2n$ and $p < 100$;
  3. AugmentedSystem() if solver.use_backslash;
  4. otherwise nothing (the iterative solver solve_iterative_tikhonov).

Arguments

  • A::AbstractMatrix{T}: data matrix of size $m \times n$.
  • b::AbstractArray{T}: right-hand side of size $m \times p$.
  • Γ::AbstractMatrix{T}: Tikhonov matrix (unused).
  • solver::TikhonovSolver{T}: solver configuration.

Returns

  • method::Union{RegularizationMethod,Nothing}: the selected method tag.
  • method_symbol::Symbol: :svd, :normal, :augmented or :auto.

Notes

  • The "condition estimate" is norm(A, 2) / norm(A, -2), i.e. a ratio of entry-wise vector norms (Frobenius norm over the $p=-2$ entry norm), not the spectral condition number. It is infinite if A has a zero entry.

  • x::AbstractMatrix{T}: regularized solution of size $n \times p$.

Solve $\mathbf{D}\mathbf{O} \approx \mathbf{R}^\top$ with a single QR decomposition $\mathbf{D} = \mathbf{Q}\mathbf{R}$ and batched triangular solves over chunks of right-hand-side columns. Internal helper.

Arguments

  • D::AbstractArray{T}: data matrix of size $K \times d$ (assumed full column rank).
  • Rt::AbstractArray{T}: right-hand-side matrix of size $K \times p$.
  • solver::LeastSquaresSolver{T}: solver configuration (chunk_size).

Returns

  • O::AbstractMatrix{T}: least-squares solution of size $d \times p$.

LiftAndLearn.solve_svd_scalar_regularization — Method
solve_svd_scalar_regularization(A, b, λ, solver)

Solve $\min_{\mathbf{x}} \|\mathbf{A}\mathbf{x} - \mathbf{b}\|_2^2 + \lambda^2\|\mathbf{x}\|_2^2$ with the SVD $\mathbf{A} = \mathbf{U}\boldsymbol{\Sigma}\mathbf{V}^\top$ as $\mathbf{x} = \mathbf{V}\,\mathrm{diag}(\sigma_i/(\sigma_i^2+\lambda^2))\,\mathbf{U}^\top\mathbf{b}$. Internal helper.

Arguments

  • A::AbstractMatrix{T}: data matrix of size $m \times n$.
  • b::AbstractArray{T}: right-hand side of size $m \times p$.
  • λ::T: regularization parameter; note that it is squared, so pass $\sqrt{\gamma}$ for $\boldsymbol{\Gamma} = \gamma\mathbf{I}$.
  • solver::TikhonovSolver{T}: solver configuration; if solver.tolerance > 0 the residual norm is logged.

Returns

  • x::AbstractMatrix{T}: regularized solution of size $n \times p$.

LiftAndLearn.solve_svd_truncation — Method
solve_svd_truncation(A, b, Γ, solver)

Solve the Tikhonov problem with an SVD of the normal-form matrix and truncation of small singular values, for (nearly) rank-deficient problems. Internal helper.

If $\boldsymbol{\Gamma} = \gamma\mathbf{I}$ with $\gamma > 0$, the problem is delegated to solve_svd_scalar_regularization. Otherwise the SVD of $\mathbf{M} = \mathbf{A}^\top\mathbf{A} + \boldsymbol{\Gamma}$ is computed; singular values below solver.tolerance * σ_max are discarded (truncated pseudoinverse) and, if none are discarded, $\mathbf{M}\mathbf{x} = \mathbf{A}^\top\mathbf{b}$ is solved directly. On OutOfMemoryError it falls back to LAPACK.gelsd! on the unregularized problem.

Arguments

  • A::AbstractMatrix{T}: data matrix of size $m \times n$.
  • b::AbstractArray{T}: right-hand side of size $m \times p$.
  • Γ::AbstractMatrix{T}: Tikhonov matrix of size $n \times n$.
  • solver::TikhonovSolver{T}: solver configuration (tolerance).

Returns

  • x::AbstractMatrix{T}: regularized solution of size $n \times p$.

vrrls!(obj, D, R, Q, γ_k, γ_km1)

Variable-regularization RLS update, where the regularization changes from γ_km1 to γ_k at this step. Internal helper.

Arguments

  • D::AbstractMatrix{T}: data block, $M \times N$.
  • R::AbstractMatrix{T}: right-hand side block, $M \times n$.
  • Q::Union{Real,AbstractMatrix{T}}: noise covariance of the block.
  • γ_k::Real: regularization at the current step.
  • γ_km1::Real: regularization at the previous step.

Returns

  • nothing; mutates obj.

Notes
